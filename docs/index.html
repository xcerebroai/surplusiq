How surplus is classified: 📋 Verified Surplus — real prayer amount extracted from a foreclosure judgment PDF, positive (sale − prayer), no kill signals. Court-verified and actionable today. The headline metric on this dashboard. Apparent Surplus — auction math only (sale − opening bid). For FL the opening bid IS the judgment amount; for OH it is the statutory 2/3-appraised figure that does NOT represent real debt — those rows need manual docket verification via the Clerk Docket link. Estimated Surplus — sale price refined by PropertyRadar's reported loan balance (only when PR returns a non-zero balance). Rare on fresh foreclosures because PR data lags. Disbursement Filed — the court has posted a notice of excess proceeds / certificate of disbursement. This filing typically arrives weeks after sale — by then leads have aged out of the 14-day freshness window, so this metric is normally $0 / 0 leads on a daily dashboard.
