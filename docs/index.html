How surplus is classified — tap to read the four tiers & what each means

📋 Verified Surplus — real debt from a court judgment (prayer amount / decree), positive (sale − debt), no kill signals. Court-verified and actionable today. The headline metric on this dashboard.

Apparent Surplus — auction math only (sale − opening bid). For FL circuit-court mortgage cases the opening bid IS the judgment amount; for OH it is the statutory 2/3-appraised figure that does NOT represent real debt; for FL county-court (HOA/condo) cases the first mortgage survives the sale, so the number is not a real surplus. These rows need manual docket verification via the Clerk Docket link.

Estimated Surplus — sale price refined by PropertyRadar's reported loan balance (only when PR returns a non-zero balance). Rare on fresh foreclosures because PR data lags.

Disbursement Filed — the court has posted a notice of excess proceeds / certificate of disbursement. This filing typically arrives weeks after sale — by then most leads have aged out of the 28-day freshness window, so this metric is usually low on a daily dashboard (confirmed leads are retained up to 90 days).
